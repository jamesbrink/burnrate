# OpenRouter

Burnrate shows your remaining **prepaid credits** (used vs. total) from the
OpenRouter credits API.

## Setup

1. Create an API key at
   [openrouter.ai/keys](https://openrouter.ai/keys).
2. In **Preferences → Add account → OpenRouter**, paste the key.

The key is stored in the OS keyring by default (plaintext storage is an
explicit opt-in per account).

## Notes

- Custom endpoints must be HTTPS (localhost excepted) — useful for proxies.
